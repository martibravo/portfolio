# Nimbus Sans

URW++'s Nimbus Sans (the Core 35 "Helvetica" clone), used as the fallback for
Helvetica Neue / Helvetica on devices that don't have them installed.

- Files: WOFF2 builds from the [`urw-core35-fonts`](https://www.npmjs.com/package/urw-core35-fonts)
  package (v1.1.0), unmodified.
- Source: the Ghostscript project's URW Core 35 fonts,
  <https://git.ghostscript.com/?p=urw-core35-fonts.git>, also available in
  OpenType, Type 1 and TrueType there.
